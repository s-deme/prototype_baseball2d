# Steam store copy draft

## タイトル

MIRACLE DIAMOND / ミラクル・ダイヤモンド

## 短い説明

狙って、引きつけて、必殺技でぶっ飛ばせ！ 打撃も投球も自分で決める、3回勝負の1人用2Dアーケード野球。

## 概要

『MIRACLE DIAMOND』は、1試合を短く濃く遊べる2Dアーケード野球ゲームです。

攻撃ではコースを読み、球をぎりぎりまで引きつけてスイング。守備ではコースと球種を選び、リリースメーターを狙って投げ込みます。プレイでたまるCLUTCH SPIRITを解放すれば、彗星スイングやまぼろしフォークが試合の流れを一変させます。

### 特徴

- 約10分で決着する3イニング制。引き分け時は最大5回まで延長
- 打つだけではなく、投球のコース・球種・タイミングも直接操作
- 攻守の必殺技と、ライバルが繰り出す対抗必殺技
- 走者、四球、押し出し、長打、本塁打、サヨナラを簡潔に再現
- 画面揺れとフラッシュを個別に軽減できるアクセシビリティ設定
- 戦績を重ねると現れる隠しスタジアムと隠しチーム
- 勝つたびに次の強敵へ進む3チームのアーケードラダー
