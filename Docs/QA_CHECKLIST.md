# Release QA checklist

## Cold start and flow

- [ ] Steam未起動状態とSteam起動状態の両方でWindowsビルドが起動する
- [ ] タイトル、遊び方、設定、戦績、終了がキーボード・XInput／Steam Input・マウスで操作できる
- [ ] 3回終了、延長、勝利、敗北、引き分け、サヨナラから結果画面へ到達する
- [ ] 再戦とタイトル復帰を10回繰り返して例外や音の多重再生がない
- [ ] 勝利時だけ次のライバルへ進み、3チーム後に先頭へ戻る
- [ ] ポーズ中のやり直し・タイトル復帰は二度押し確認され、通常復帰は即時
- [ ] Alt+Tab、最小化、フォーカス復帰で入力と音が壊れない

## Rules and persistence

- [ ] 三振、四球、押し出し、単打、二塁打、三塁打、本塁打、3アウト交代が正しい
- [ ] サヨナラ単打では勝ち越しに必要な得点だけが入る
- [ ] 3勝後に月影スタジアムが解放され、再起動後も保持される
- [ ] 現在のライバル、現在連勝、最高連勝が再起動後も正しく保持される
- [ ] 音量、画面揺れ、フラッシュ軽減、戦績が再起動後も保持される
- [ ] セーブデータなし、既存データありの両方で起動する

## Presentation and accessibility

- [ ] 1280×720、1920×1080、2560×1440、1366×768、16:10、ウルトラワイドで重要UIが切れない
- [ ] 日本語グリフが欠けず、スコア・カウント・操作説明が重ならない
- [ ] 選択フォーカスが色だけでなく白枠とマーカーで判別できる
- [ ] フラッシュ軽減ONで強い全画面発光が抑えられる
- [ ] 画面揺れOFFですべての揺れが停止する
- [ ] 音量0で無音、10でクリッピングや不快なピークがない
- [ ] 安定して60fpsを維持し、GCによる目立つ停止がない

## Store evidence

- [ ] 実ビルドから1920×1080以上のゲームプレイスクリーンショットを5枚以上撮影する
- [ ] ストアに記載した機能がすべて提出ビルドに存在する
- [ ] Windows 10/11 x64のクリーン環境でインストール・起動・アンインストールを確認する
- [ ] Xbox系XInputとSteam Input経由のPlayStation系コントローラー実機で、表記どおり操作できる
- [ ] `Player.log` に例外、MissingReference、シェーダーエラーがない
